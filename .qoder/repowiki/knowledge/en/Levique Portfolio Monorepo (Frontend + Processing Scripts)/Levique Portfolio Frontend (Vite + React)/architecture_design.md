Entry point `src/main.tsx` mounts the root `<App />` under React StrictMode and imports global styles from `index.css`. `src/App.tsx` is the single-page shell: it owns all routing state (`activeChapter`, `navOpen`, `showNav`, `isUnfolded`) via `useState`, drives section tracking through an `IntersectionObserver` over `section[id]` elements, and renders eight chapters (About, Skills, Experience, Leadership, Projects, Certifications, Future, Contact) as sibling `<section>` elements. The only extracted component lives in `src/components/TalkingPortrait.tsx`, which implements a self-contained photorealistic face animation on a 1024×1024 `<canvas>` driven by `requestAnimationFrame`, synchronized to `/audio/introduction.mp3` via Web Audio `AnalyserNode` frequency data; it exposes no props beyond its default export. Dependency direction is strictly one-way: `App.tsx → TalkingPortrait`; there are no services, stores, or API layers inside this module. Styling is centralized in `index.css` (BEM-style class names like `chapter-coral`, `intro-curtain`, `tp-container`) with inline `style` overrides used sparingly for per-frame transforms.
