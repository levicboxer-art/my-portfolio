Flat collection of independent Node.js CLI scripts with no shared library — each file is a self-contained one-shot tool invoked directly via `node`. Two broad sub-groups coexist:
- Pixel/audio inspection tools (e.g. `defilter_png.cjs`, `align_check.cjs`, `inspect_mouth.cjs`, `check_audio.cjs`, `parse_mp3.cjs`) read raw bytes from `public/images/portrait.png` and generated JPEGs under a Gemini temp path, using `pngjs` and `jpeg-js` to walk RGBA buffers and compute luminance/alignment metrics.
- Source-code rewriters (`rewrite_app.cjs`, `update_css.cjs`, `full_css_update.cjs`, `update_layout.cjs`, `update_about.cjs`, `update_choco.cjs`, etc.) read `src/App.tsx` / `src/index.css` / `src/App.tsx.backup`, apply regex extraction or string concatenation, and write back the modified file.
The `scripts/` subdirectory holds related image-patch generation helpers (`generate_patches.cjs`, `calibrate_patches.cjs`, `test_composite.cjs`, `inspect_base_mouth.cjs`). There is no package.json or entry point; dependency direction is one-way: scripts depend on the repo's public assets and source tree but never on each other.
